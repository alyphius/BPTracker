# BP Tracker

An offline Android blood pressure logging application.

## Features
- Save systolic and diastolic readings
- Record optional pulse readings
- Automatically record date and time
- View saved reading history
- Store readings locally on the device

## Technology
- Python
- Kivy
- Buildozer
- GitHub Actions

## Build
Push this project to the main branch of a GitHub repository.
GitHub Actions will build the Android APK.
Download the APK from the workflow run's Artifacts section.
